# Инструкция для канала (короткая, копировать целиком)

Готовый текст для раздачи. Полная версия: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

```
🤖 Установка AI-Panel

Claude Code на твоём сервере, работает через браузер. Комп держать
включённым не нужно.

⚠️ Нужен сервер (VPS) на Ubuntu 22.04 / 24.04.
Нет сервера? Арендуй любой (Timeweb, Hetzner, Aeza), образ Ubuntu, мин. 2 ГБ RAM.
Провайдер пришлёт IP и пароль — подключись по SSH:
    ssh root@IP_СЕРВЕРА

📦 Подготовь одну вещь:
🔑 Ключ Claude — console.anthropic.com/keys
   (или подписка Pro/Max — тогда войдёшь на сервере один раз)

⚙️ И открой порт 80 в панели провайдера (security group).

━━━━━━━━━━━━━━━━━━
✅ Установка (вставь в терминал СЕРВЕРА, замени ключ на свой):

curl -sSL https://raw.githubusercontent.com/ifinance25/claude-UI/main/scripts/install.sh | sudo ANTHROPIC_API_KEY=sk-ant-КЛЮЧ bash

━━━━━━━━━━━━━━━━━━
✍️ Или проще — установщик сам всё спросит:

curl -sSL https://raw.githubusercontent.com/ifinance25/claude-UI/main/scripts/install.sh | sudo bash

Спросит три вещи, любую можно пропустить клавишей Enter:
   домен (нет домена → Enter, будешь заходить по IP)
   ключ Claude
   токен Telegram-бота (не нужен → Enter, останется веб)

(вставил значение → нажми Enter; без Enter кажется «зависшим»)

━━━━━━━━━━━━━━━━━━
🎉 В конце увидишь адрес сайта + логин admin + пароль — сохрани,
пароль показывается один раз!

📁 Положи свой проект на сервер отдельной папкой:

sudo -u vels-bot git clone https://github.com/ты/твой-проект.git /var/lib/vels-bot/projects/твой-проект

Перезапускать ничего не надо — проект появится сам.

🤖 Хочешь ещё и Telegram-бота? Возьми токен у @BotFather (/newbot) и свой ID
у @userinfobot, потом просто повтори команду установки и введи их — настройки
и чаты останутся на месте.

🔄 Обновление — та же команда установки. Данные целы.
```
