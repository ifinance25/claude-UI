# AI-Panel — установка

Одна команда на сервере → готовый веб-интерфейс к Claude Code. Всё, что нужно
дальше, — адрес и пароль из финального сообщения установщика.

---

## В двух словах

Нужен **VPS** на Ubuntu и **доступ к Claude** (API-ключ или подписка Pro/Max).
Зайдите на сервер по SSH и выполните:

```bash
curl -sSL https://raw.githubusercontent.com/ifinance25/claude-UI/main/scripts/install.sh | sudo bash
```

Установщик спросит домен, ключ Claude и — необязательно — токен Telegram-бота,
остальное сделает сам и в конце покажет **адрес** и **пароль администратора**.

> Установщик скачивает публичный релиз-архив и проверяет его контрольную сумму —
> никаких токенов доступа вводить не нужно.

---

## Что подготовить

1. **Сервер (VPS)** на Ubuntu 22.04/24.04 с доступом по `sudo` и публичным IP.
   Минимум 2 ГБ RAM.
2. **Доступ к Claude** — одно из двух:
   - **API-ключ** с [console.anthropic.com/keys](https://console.anthropic.com/keys) —
     оплата по факту, ничего не нужно открывать в браузере (**рекомендуется**);
   - подписка **Claude Pro/Max** — тогда один раз авторизуетесь на сервере
     командой, которую установщик напечатает.
3. **Откройте порт 80** (и **443** для домена) в облачной *security group* —
   единственный шаг, который установщик не делает сам.
4. **Telegram-бот — по желанию.** Нужен — приготовьте токен от
   [@BotFather](https://t.me/BotFather) (`/newbot`) и свой числовой ID от
   [@userinfobot](https://t.me/userinfobot). Не нужен — пропустите вопрос.

## Варианты установки

### Вариант 1 — только веб, без вопросов

```bash
curl -sSL https://raw.githubusercontent.com/ifinance25/claude-UI/main/scripts/install.sh | sudo \
  ANTHROPIC_API_KEY=sk-ant-ВАШ_КЛЮЧ \
  bash
```

Адрес будет `http://<ip-сервера>/agent`.

### Вариант 2 — со своим доменом и HTTPS

Сначала направьте A-запись домена на IP сервера и откройте порты 80 и 443:

```bash
curl -sSL https://raw.githubusercontent.com/ifinance25/claude-UI/main/scripts/install.sh | sudo \
  DOMAIN=claude.ваш-домен.ru \
  ANTHROPIC_API_KEY=sk-ant-ВАШ_КЛЮЧ \
  bash
```

Caddy сам выпустит TLS-сертификат. Адрес: `https://claude.ваш-домен.ru`.

### Вариант 3 — сразу с Telegram-ботом

Добавьте к любой команде выше:

```bash
  TELEGRAM_BOT_TOKEN=123456:ВАШ_ТОКЕН \
  ALLOWED_USER_IDS=ВАШ_TELEGRAM_ID \
```

### Вариант 4 — установщик спросит вживую

```bash
curl -sSL https://raw.githubusercontent.com/ifinance25/claude-UI/main/scripts/install.sh | sudo bash
```

Вопросов три, и каждый можно пропустить клавишей Enter:

| Вопрос | Enter означает |
|---|---|
| Домен | домена нет → доступ по IP |
| Claude API-ключ | добавите позже (или входите подпиской) |
| Токен Telegram-бота | бот не нужен → только веб |

> **Вставили значение — нажмите Enter.** Без Enter установщик ждёт ввод и
> кажется зависшим.

> Вместо ключа можно отдать токен подписки: `CLAUDE_CODE_OAUTH_TOKEN=...`,
> он получается командой `claude setup-token` на машине с браузером.

## Что делает установщик

1. Ставит зависимости: Python, Node.js, Claude Code CLI, **Caddy**.
2. Создаёт сервис `vels-claude` с автозапуском и перезапуском при сбоях.
   Без токена бота сервис поднимает только веб, с токеном — веб и Telegram.
3. Скачивает код и собирает веб-интерфейс.
4. Поднимает приложение **внутри** на `127.0.0.1:8765`, наружу отдаёт через
   Caddy: `http://<ip>/agent` или `https://домен`.
5. Генерирует пароль администратора и показывает его **один раз** в конце.

В конце вы увидите примерно:

```
AI-Panel installation complete.
Telegram bot:   не настроен (интерфейс только веб)
Web UI:         http://203.0.113.5/agent
Admin login:    admin
Admin password: a1b2c3d4e5f6   <-- СОХРАНИТЕ, показан один раз!
Claude auth:    через ANTHROPIC_API_KEY — ручной вход не нужен
```

## После установки

1. Откройте адрес из финального сообщения → страница входа.
2. Войдите: `admin` и пароль из финала.
3. Положите свой проект в `/var/lib/vels-bot/projects` отдельной подпапкой:

   ```bash
   sudo -u vels-bot git clone https://github.com/вы/ваш-проект.git \
     /var/lib/vels-bot/projects/ваш-проект
   ```

   Перезапуск не нужен. Проект появится в списке; новые также создаются в админке по имени.
4. Напишите Claude любое сообщение — если пришёл ответ, всё работает.

---

## Проверка за минуту

- [ ] Адрес из финала открывается → видна страница входа.
- [ ] Вход `admin` + пароль → грузится интерфейс.
- [ ] Сообщение Claude → приходит ответ.
- [ ] Если ставили с ботом: `/start` в Telegram → бот отвечает.

Сервис запущен, а снаружи не открывается — почти всегда закрыт порт 80/443 в
облачной security group.

---

## Обновление

Повторите команду установки: скачается свежий релиз, код обновится, фронт
пересоберётся, сервис перезапустится. `.env`, база чатов и папка проектов не
трогаются.

```bash
curl -sSL https://raw.githubusercontent.com/ifinance25/claude-UI/main/scripts/install.sh | sudo bash
```

Тем же способом подключается Telegram-бот к уже работающей установке: запустите
установщик снова и введите токен, когда он спросит.

## Удаление

```bash
sudo bash /opt/vels-claude/scripts/uninstall.sh
```

Спросит подтверждение. Папка проектов и авторизация Claude сохраняются.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Установщик «завис» на вводе | Не нажали **Enter** после вставки значения |
| Адрес не открывается снаружи | Откройте порт **80** (и **443** для домена) в security group провайдера |
| `Claude auth: НЕ авторизован` в финале | Передайте `ANTHROPIC_API_KEY=...` и повторите установку, либо войдите подпиской — установщик печатает точную команду |
| `Токен не принят Telegram` | Проверьте токен у @BotFather и введите заново; либо Enter, чтобы поставить без бота |
| Бот не отвечает, веб работает | Ваш ID должен быть в `ALLOWED_USER_IDS`, а бот — **админом форум-группы** с правом «Управление темами» (в личке темы не работают) |
| Домен не открывается по https | A-запись должна указывать на IP, порт 443 открыт; логи: `journalctl -u caddy -n 50` |
| В интерфейсе не тот проект | Выберите нужный в сайдбаре или в админке |
| Диагностика сервиса | `systemctl status vels-claude` · `journalctl -u vels-claude -n 80 --no-pager` |
