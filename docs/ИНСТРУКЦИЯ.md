# AI-Panel — инструкция пользования

От установки до ежедневной работы. Подходит для раздачи участникам как есть.

---

## Что это

Claude Code, развёрнутый на вашем сервере и доступный через браузер. Вы даёте
ему задачи по своему проекту — он читает и правит файлы прямо на сервере.
Компьютер держать включённым не нужно: работает сервер.

В панели: несколько проектов, файловый менеджер, админка, участники и доступы.

---

## Шаг 1. Что подготовить

1. **Сервер (VPS)** на Ubuntu 22.04/24.04 с доступом по `sudo` и публичным IP
   (Timeweb, Hetzner, Aeza, DigitalOcean — любой, минимум 2 ГБ RAM).
2. **Доступ к Claude** — одно из двух:
   - **API-ключ** с [console.anthropic.com/keys](https://console.anthropic.com/keys) —
     оплата по факту использования, ничего не нужно открывать в браузере;
   - подписка **Claude Pro/Max** — тогда один раз авторизуетесь на сервере.
3. **Откройте порт 80** (и **443**, если будет домен) в облачной *security
   group* провайдера — единственный шаг, который установщик не делает сам.

**Telegram-бот не обязателен.** Нужен он вам или нет — решаете при установке;
подключить можно и потом.

---

## Шаг 2. Установка (одна команда)

Зайдите на сервер по SSH и выполните:

```bash
curl -sSL https://raw.githubusercontent.com/ifinance25/claude-UI/main/scripts/install.sh | sudo bash
```

Установщик спросит:

- **домен** — впишите свой, если есть; пусто (Enter) = доступ по IP;
- **Claude API-ключ** — вставьте `sk-ant-...` или Enter, чтобы пропустить;
- **токен Telegram-бота** — Enter, если бот не нужен.

> **Вставили значение — нажмите Enter.** Без Enter установщик ждёт ввод и
> кажется зависшим.

### Без вопросов, одной строкой

Только веб, без Telegram:

```bash
curl -sSL https://raw.githubusercontent.com/ifinance25/claude-UI/main/scripts/install.sh | sudo \
  ANTHROPIC_API_KEY=sk-ant-ВАШ_КЛЮЧ \
  bash
```

Со своим доменом и HTTPS (сначала направьте A-запись домена на IP сервера):

```bash
curl -sSL https://raw.githubusercontent.com/ifinance25/claude-UI/main/scripts/install.sh | sudo \
  DOMAIN=claude.ваш-домен.ru \
  ANTHROPIC_API_KEY=sk-ant-ВАШ_КЛЮЧ \
  bash
```

Сразу с Telegram-ботом — добавьте к любой из команд:

```bash
  TELEGRAM_BOT_TOKEN=123456:ВАШ_ТОКЕН \
  ALLOWED_USER_IDS=ВАШ_TELEGRAM_ID \
```

В конце установщик покажет **адрес** и **пароль администратора** — сохраните,
пароль показывается один раз.

---

## Шаг 3. Первый вход

1. Откройте адрес из финального сообщения: `http://<ip-сервера>/agent` или
   `https://ваш-домен`.
2. Логин `admin`, пароль из финального сообщения.
3. Напишите Claude любое сообщение. Ответ пришёл — всё работает.

Ответа нет и в интерфейсе видно, что Claude не авторизован:

```bash
echo 'ANTHROPIC_API_KEY=sk-ant-ВАШ_КЛЮЧ' | sudo tee -a /opt/vels-claude/.env >/dev/null
sudo systemctl restart vels-claude
```

---

## Шаг 4. Свой проект

Папка проектов на сервере — `/var/lib/vels-bot/projects`. Положите проект
**отдельной подпапкой** внутрь неё:

```bash
sudo -u vels-bot git clone https://github.com/вы/ваш-проект.git \
  /var/lib/vels-bot/projects/ваш-проект
```

Перезапускать сервис не нужно — проект появится сам.

Проекты лежат подпапками в `PROJECTS_DIR`. Новые можно создать в админке по
имени (путь = каталог проектов + имя). В сайдбаре выбирается нужный проект.

## Telegram

Бот ведёт диалоги в **форум-группе** — в личной переписке темы не работают,
это ограничение Telegram.

**Подключить при установке:** передайте `TELEGRAM_BOT_TOKEN` и
`ALLOWED_USER_IDS` в команде или введите токен, когда установщик спросит.

**Подключить позже:** повторите ту же команду установки и на вопрос про токен
введите его. Установщик подхватит все прежние настройки, перепишет systemd-юнит
на режим «бот + веб» и перезапустит сервис. Ваши чаты, пароль и проекты не
пострадают.

```bash
curl -sSL https://raw.githubusercontent.com/ifinance25/claude-UI/main/scripts/install.sh | sudo bash
```

Или сразу без вопросов:

```bash
curl -sSL https://raw.githubusercontent.com/ifinance25/claude-UI/main/scripts/install.sh | sudo \
  TELEGRAM_BOT_TOKEN=123456:ВАШ_ТОКЕН \
  ALLOWED_USER_IDS=ВАШ_TELEGRAM_ID \
  bash
```

**Что нужно со стороны Telegram:**

1. Токен бота — [@BotFather](https://t.me/BotFather), команда `/newbot`.
2. Ваш числовой ID — [@userinfobot](https://t.me/userinfobot).
3. Создайте группу → в настройках включите **«Темы» (Topics)**.
4. Добавьте бота **администратором** с правом **«Управление темами»**.
5. Создайте тему задачи — бот пришлёт приветствие и список проектов.

Бот отвечает только тем Telegram ID, которые перечислены в `ALLOWED_USER_IDS`.

---

## Обновление

Повторите команду установки — скачается свежая версия, `.env`, база чатов и
проекты не пострадают:

```bash
curl -sSL https://raw.githubusercontent.com/ifinance25/claude-UI/main/scripts/install.sh | sudo bash
```

## Удаление

```bash
sudo bash /opt/vels-claude/scripts/uninstall.sh
```

Папка проектов и авторизация Claude сохраняются.

---

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Сайт не открывается снаружи | Откройте порт **80** (и **443** для домена) в security group провайдера |
| Чат не отвечает, Claude не авторизован | Добавьте ключ командой из Шага 3 или переустановите с `ANTHROPIC_API_KEY=` |
| Установщик «завис» на вводе | Не нажали **Enter** после вставки значения |
| `Токен не принят Telegram` | Проверьте токен у @BotFather — установщик переспросит, перезапускать не нужно; либо Enter, чтобы поставить без бота |
| Бот не отвечает, веб работает | Бот должен быть **админом форум-группы** с правом «Управление темами»; ваш ID — в `ALLOWED_USER_IDS` |
| В списке виден не тот проект | Выберите проект в сайдбаре или в админке |
| Диагностика | `systemctl status vels-claude` · `journalctl -u vels-claude -n 80 --no-pager` |
