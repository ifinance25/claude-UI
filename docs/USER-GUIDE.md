# AI-Panel — как пользоваться

**AI-Panel** — это Claude Code, который живёт на вашем сервере и
работает через браузер. Вы пишете ему как в обычном чате, а он читает и правит
файлы вашего проекта, запускает команды и отвечает на вопросы. Сервер работает
всегда, поэтому свой компьютер держать включённым не нужно.

В панели несколько проектов, файловый менеджер, админка, участники и доступы.

---

## Диалоги

Слева — список ваших чатов, сгруппированный по дате. Кнопка **«Новый чат»**
открывает диалог: можно выбрать проект и папку. Название чата подставляется
само из первого сообщения.

Поиск над списком ищет по названиям и содержимому чатов.

---

## Поле ввода

- **Enter** — отправить, **Shift+Enter** — перенос строки.
- **Скрепка** — приложить файл к сообщению (Claude увидит его содержимое).
- **Название модели** рядом с полем — переключение между Opus, Sonnet, Haiku и
  другими доступными моделями. Выбор запоминается.
- **Стоп** — прерывает генерацию, пока Claude отвечает. Диалог сохраняется,
  можно сразу писать следующее сообщение.

Над полем ввода видны расход токенов, стоимость и заполнение контекстного окна
текущего диалога. Когда окно близко к пределу, появится подсказка сжать
историю командой `/compact`.

---

## Документация

Кнопка **«Документация»** в шапке чата открывает эту памятку и файлы из папки
`docs/` вашего проекта, если они там есть.

---

## Команды

Всё, что начинается со слэша, показывается в меню при вводе `/`.

**Команды Claude** — выполняет он сам:

- `/cost` — расход токенов и стоимость;
- `/context` — сколько занято контекстного окна;
- `/compact` — сжать историю диалога, освободив контекст;
- `/init` — создать или обновить `CLAUDE.md` проекта;
- `/review` — ревью изменений;
- `/diff` — незакоммиченные правки;
- `/clear` — очистить историю диалога;
- `/security-review` — проверка кода на уязвимости.

Набор зависит от проекта и установленных плагинов.

**Команды сервиса** — их обрабатывает сам AI-Panel, потому что Claude
Code понимает их только в интерактивном терминале:

| Команда | Что делает |
|---|---|
| `/model` | Показать текущую модель |
| `/model sonnet` | Переключиться на Sonnet |
| `/model opus` | Переключиться на Opus |
| `/config` | Показать настройки Claude Code |
| `/mcp` | Список подключённых MCP-серверов |
| `/permissions` | Текущий режим разрешений |

---

## Скиллы

**Скиллы** — готовые сценарии, которые расширяют Claude: разбор задачи
вопросами, ревью по чек-листу, пошаговая отладка. Claude подбирает подходящий
сам, когда задача того требует. Можно позвать явно — просто назовите скилл в
сообщении.

---

## Telegram (если подключён)

Telegram-бот — необязательная часть: если при установке вы пропустили токен, его
просто нет, и всё работает через браузер. Когда бот подключён, диалоги ведутся в
темах форум-группы, а к командам выше добавляются:

| Команда | Что делает |
|---|---|
| `/start` | Приветствие, список проектов |
| `/status` | Статус текущей сессии |
| `/close` | Закрыть сессию |
| `/stop` | Прервать генерацию |
| `/help` | Справка |

Как подключить бота потом — в `docs/ИНСТРУКЦИЯ.md`, раздел «Telegram».
